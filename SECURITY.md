# Security Policy

sqlh is pre-release software. There is no stable release or guaranteed support
response time.

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting feature for this repository. Do not post vulnerability details in a
public issue or discussion.

If private reporting is unavailable, do not disclose the vulnerability
publicly. Use an existing private contact method or wait until private
reporting is enabled.

Include the affected version or commit, the impact, and concise reproduction
steps. Do not send credentials, connection strings, production data, or other
secrets.

Reports are reviewed as maintainer availability permits. Please coordinate
public disclosure with the maintainers; no response or remediation timeline is
guaranteed.
