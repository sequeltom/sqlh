sqlh - SQL Server query tool for agents. Read-only by default; compact typed output. --version, --help

USAGE
  sqlh [connection] [options] -Q "SQL"          (or the SQL as the only argument)
  sqlh [connection] [options] -i file.sql [-i more.sql]     (or SQL on stdin: <SQL> | sqlh ...)

EXAMPLES  (same in cmd.exe, PowerShell and Git Bash)
  sqlh -S myserver -d AppDb -Q "SELECT TOP 5 * FROM dbo.Orders WHERE Status = 'Open' ORDER BY Id DESC"
  sqlh -S myserver,1433 -U reader -d AppDb -i report.sql   (password: env SQLCMDPASSWORD)
  sqlh --profile dev describe sys.dm_exec_requests   (its columns and types: see SCHEMA)
  sqlh --profile dev -i "my queries\report.sql" -o report.txt
  SQL with " $ % ` or several lines goes in a file (-i). Quote -S "host\inst" and paths with spaces.
  Paths: C:/dir/f.sql works everywhere; C:\dir\f.sql needs quotes in Git Bash; /c/dir/f.sql is Git Bash only.
  Piped non-ASCII must be UTF-8: chcp 65001 (cmd.exe), $OutputEncoding = [Text.Encoding]::UTF8 (PS 5.1)

CONNECTION
  --profile NAME  use a saved profile (sqlh profiles add makes one; env SQLH_PROFILE). Without -S: the default one
  -S server       host | host\instance | host,port   (env SQLCMDSERVER; default .)
  -d database     (env SQLCMDDBNAME); default: the profile's, else the login's (often master)
  -E              Windows auth (default without -U)  -Ns|-Nm|-No encrypt strict|mandatory (default)|optional
  -C              trust the server certificate (self-signed servers); profiles add NAME -C saves it
  -U login        SQL login (env SQLCMDUSER); password from the profile or SQLCMDPASSWORD; no -P
  -l seconds      login timeout (default 15; 0 = none), one attempt   -K ReadOnly   -M multi-subnet failover

EXECUTION
  -i file         input file, repeatable; "-i -" reads stdin. UTF-8, or UTF-16 with a BOM
  -v n=v ...      values for $(n); environment variables also resolve, not SQLCMDPASSWORD. -x turns this off
  -c word         batch separator (default GO; "GO 3" runs a batch 3 times)
  -t seconds      per-batch query timeout, also for a stalled reader (default 60; 0 = none)
  --lock-timeout S      seconds a statement waits for a lock, then error 1222 (default 10; 0 = none)
  --read-uncommitted    read-only runs only: read without waiting for writers; rows may be dirty
  --allow-write   permit writes. Without it, writes other than to #temp/@table are refused before anything
                  runs; every batch runs in a rolled-back transaction. Not security: use a read-only login.
  --check         compile only (SET NOEXEC ON): finds syntax errors and unknown columns, not missing tables
  --continue-on-error   run later batches after one fails (default: stop)

OUTPUT
  --format F      text (default) | json (one document; exit status last) | csv (data; -- lines on stderr)
  --max-rows N    rows per result set (default 100; 0 = all, within --max-output). Read-only runs count the rest for
                  250 ms (5 s if statements follow in its batch): "≥N" is a lower bound (--exact-count counts all)
  --max-cell N    characters per value (default 500)   --max-results N  result sets (default 20)
  --max-output N  total output bytes (default 1000000; 0 = no limit); the run still finishes
  -o file         write output to a file (replaced whole when the run ends; never an input)
  --verbose       connection diagnostics on stderr

SCHEMA  describe|def|deps NAME | tables [PATTERN] | find PATTERN [--text] | dbs | info   (current database)
  describe: columns, keys, indexes, FKs, params. def: source. deps: uses, used_by. PATTERN: Ord, Ord*, dbo.?rd*

PROFILES  sqlh profiles ... saves and manages them; --profile NAME uses one. Passwords stay in Credential Manager
  sqlh profiles add NAME -S server [-d db] [-U login] [--write-policy deny|flag|allow] [--description TEXT]
  sqlh profiles list [--search TEXT] | test NAME | rm NAME  (new profiles deny writes; --new-password re-asks)
  sqlh mcp --profile NAME [--profile NAME ...]   MCP server on stdio for harnesses: read-only tools

FORMAT
  "-- " lines are metadata: "-- result N", a header of name:type columns, tab-separated rows,
  "-- N rows". NULL is NULL; the string 'NULL' is \NULL. Escapes \t \n \r \\ (one backslash) cover
  values and the names and paths in -- lines. A cut value ends …[+N]. Errors map to input lines.
  Last line: "-- ok: ...", "-- partial: ..." (exit 0; a stopped count cut statements) or "-- failed (exit N): ...".

EXIT CODES
  0 ok or partial  1 SQL error  2 connect/login failed  3 usage  4 timeout  5 blocked  6 cancelled
  7 output not delivered (reader gone or stalled, or -o failed)  10 internal error (both may lose the last line)
